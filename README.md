# Портфолио

Минималистичный адаптивный сайт-портфолио. Откройте `index.html` в браузере.

## Состав проекта

- `projects.js` — профиль, категории и карточки работ.
- `assets/portfolio/` — оптимизированные превью и исходные PDF-проекты, связанные из карточек.
- `archive/Портфолио.rar` — исходный архив работ.
- `archive/unpacked/` — оригиналы архива с сохранённой структурой подпапок.
- `output/pdf/` — исходное и сокращённое резюме Алисы.

Каждая отдельная работа показана своей карточкой внутри категории. Например, каждая визитка, карточка товара и плакат имеют отдельный блок. Обложка и внутренние страницы одного многостраничного издания остаются галереей одного проекта. Пропорции превью подстраиваются под исходное изображение; откройте карточку, чтобы листать изображения и открыть полноформатный PDF.

Кнопки фильтров повторяют названия папок из архива: `Брендбук`, `Вёрстка`, `Визитка`, `Карточки для маркетплейсов`, `Макеты мобильных приложений`, `Макеты сайтов`, `Плакаты`, `Планшеты для студентов`, `Работы из Малинки`, `Упаковка` и `Фирменный стиль`. Все 60 страниц брендбука SoundWave доступны в галерее; PDF-оригиналы остальных многостраничных работ открываются из карточек.

## Добавление новых работ

Положите оптимизированные превью в `assets/portfolio/`, затем добавьте проект в массив `projects` в `projects.js`. Укажите заголовок, категорию, краткое описание, `cover`, список `images` и (при наличии) `sourceFiles` со ссылками на PDF.

## Публикация

Загрузите `index.html`, `styles.css`, `script.js`, `projects.js` и папку `assets/portfolio/` на статический хостинг. Папка `archive/` хранит оригиналы и распаковку; сайту для показа карточек она не нужна.
